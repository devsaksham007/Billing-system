# Library Management System

An object-oriented Python example for managing books and library members.

## Features

- Add and remove physical and electronic books
- Register members and issue or return books
- Inheritance and polymorphism through `EBook(Book)` and `display_details()`
- Custom exception handling for invalid library operations
- Uses `math`, `random`, and `datetime`

## Run

```bash
python library_management.py
```
